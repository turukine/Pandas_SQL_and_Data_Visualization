# Визуализация данных: Pandas, SQL и графики

## Описание проекта
Проект по анализу и визуализации данных студентов образовательной платформы. Исследуется поведение пользователей через различные типы графиков с использованием трех библиотек: Matplotlib, Seaborn и Plotly.

## 🎯 Цели проекта
- Освоить основные техники визуализации данных
- Научиться работать с разными библиотеками для построения графиков
- Проанализировать паттерны поведения пользователей
- Сравнить активность в разное время суток и дни недели

## 📊 Выполненные упражнения

### Обязательная часть

| Упражнение | Тип графика | Задача |
|------------|-------------|--------|
| **ex00** | Линейный график | Просмотры страниц по дням |
| **ex01** | Линейный с стилями | Сравнение просмотров и коммитов |
| **ex02** | Столбчатая диаграмма | Активность по времени суток |
| **ex03** | Группированные столбцы | Рабочие дни vs выходные |
| **ex04** | Гистограмма | Распределение коммитов |
| **ex05** | Boxplot | Сравнение групп пользователей |
| **ex06** | Scatter Matrix | Корреляции между метриками |
| **ex07** | Heatmap | Активность по дням и часам |
| **ex08** | Seaborn | Временные ряды коммитов |

## 🔍 Ключевые инсайты

### Активность пользователей
- **Пиковое время**: вечер (17:00-23:59) - наиболее продуктивный период
- **Дни недели**: разные паттерны активности в рабочие дни и выходные
- **Лидеры**: user_7 - постоянный лидер по коммитам

### Статистические находки
- Сильная корреляция между просмотрами страниц и коммитами
- Различное распределение активности в тестовой и контрольной группах
- Наличие выбросов в данных о дедлайнах

### Визуальные паттерны
- Heatmap показал часы наименьшей активности
- Scatter matrix выявил нелинейные зависимости
- Анимация Plotly наглядно показала динамику лидерства

## 🛠 Технологии и инструменты
- **Язык**: Python 3
- **Анализ данных**: Pandas, SQLite
- **Визуализация**: Matplotlib, Seaborn, Plotly
- **Среда**: Jupyter Notebook
